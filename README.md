# DAF E-Learning Catalog

Static course catalog prototype for Air National Guard training references.

The public site is generated from a local course spreadsheet and presents the courses as a book-style catalog with section navigation, page controls, course frequency, regulation references, and standards tags.

## Public Files

- `index.html` - page structure
- `styles.css` - book layout and visual design
- `app.js` - generated course data and catalog behavior

## Source Files

The working spreadsheet and standards reference documents are intentionally not committed to the public repository.
