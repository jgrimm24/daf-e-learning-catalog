# DAF Safety Training Catalog How-To Video

Target length: 2 to 3 minutes

Audience: ANG members using the catalog from NIPR or a desktop browser

Tone: Direct, practical, and focused on how to find training quickly

## Recording Setup

1. Open the catalog at https://jgrimm24.github.io/daf-e-learning-catalog/
2. Use a desktop browser window around 1400 by 900 if possible.
3. Make sure the catalog is in Desktop mode.
4. Record the browser window only.
5. Read the narration below while following the click path.

## Shot List And Narration

### 1. Opening View

On screen: Main catalog page, showing the title, browse list, book, and right-side frequency filter.

Narration:

Welcome to the DAF Safety Training Catalog. This guide helps you find safety, health, environmental, flight, and weapons training available on DAF E-Learning.

The catalog is built to work like a book. You can browse by training area, search for a specific topic, filter by training frequency, and copy clean training links for use on NIPR.

### 2. Browse By Training Area

Click path:

1. Select Occupational Safety.
2. Expand or select Weapons Safety.
3. Select one course from the expanded list if visible.

Narration:

On the left side, use Browse to move through the major training areas. Select a training area to jump to that section of the catalog.

Some areas can expand to show individual courses, which helps you get to a module without flipping through every page.

### 3. Search

Click path:

1. Click the Search field.
2. Type "fire extinguisher".
3. Select the matching result.
4. Clear the search field.

Narration:

If you know what you are looking for, use Search. You can search by course title, topic, regulation, or requirement.

For example, searching fire extinguisher brings up the fire extinguisher course directly. Select the result to jump to that page.

### 4. Frequency Filter

Click path:

1. On the right side, open Training cycle.
2. Select Annual training.
3. Open Training area.
4. Select Occupational Safety.
5. Select one listed course.
6. Change Training cycle to Three years.

Narration:

On the right side, the Frequency filter helps you find recurring requirements.

Choose a training cycle, such as Annual training or Three years. Then choose the training area, such as Occupational Safety, Weapons Safety, or Flight Safety.

The matching courses appear below the filters. Select any course to jump straight to it in the catalog.

### 5. Copy Training Links On NIPR

Click path:

1. Go to a course with a Copy training link button.
2. Click Copy training link.
3. Open a new browser tab.
4. Paste the link into the address bar, but do not complete login during recording.

Narration:

For NIPR users, training links work best when they are copied and pasted into a new tab.

Select a course, click Copy training link, open a new browser tab, and paste the link into the address bar.

This avoids several redirect issues that can happen when links are opened directly through search results, email, or security redirects.

### 6. DAF E-Learning Home Page Link

Click path:

1. Return to the first spread.
2. Click Copy DAF E-Learning Home Page Link.
3. Open a new tab.
4. Paste the link into the address bar.

Narration:

The first page also includes a copy button for the DAF E-Learning Safety Home Page.

Use the same process: copy the clean link, open a new tab, and paste it directly into the browser.

### 7. Mobile View

Click path:

1. Click Mobile mode.
2. Swipe or use the next arrow to move through pages.
3. Point out that training links are hidden.
4. Click Desktop mode again.

Narration:

Mobile mode is designed for quick reference. It shows one page at a time and supports swiping through the catalog.

Training links are hidden on mobile because DAF E-Learning access is more reliable from desktop and NIPR. Use Desktop mode when you need to copy training links.

### 8. Closing

On screen: Return to the main catalog view.

Narration:

That is the basic workflow. Browse by area, search by topic, filter by frequency, and copy clean links when using NIPR.

Use the direct catalog address when sharing the site: https://jgrimm24.github.io/daf-e-learning-catalog/

## Short Version Script

Welcome to the DAF Safety Training Catalog. This site helps you find safety, health, environmental, flight, and weapons training available on DAF E-Learning.

Use Browse on the left to move by training area. Select a section like Occupational Safety, Weapons Safety, or Flight Safety to jump through the catalog.

If you already know what you need, use Search. You can search by course title, topic, regulation, or requirement.

On the right, use the Frequency filter to find recurring training. Choose a training cycle, then choose the training area. The matching courses appear below, and selecting a course jumps you directly to that page.

For NIPR users, do not open training links directly. Select the course, click Copy training link, open a new browser tab, and paste the link into the address bar. The home page link works the same way.

Mobile mode is for quick reference and page swiping. Training links are hidden on mobile, so use Desktop mode when you need to copy links.

When sharing the catalog, use the direct site address: https://jgrimm24.github.io/daf-e-learning-catalog/
